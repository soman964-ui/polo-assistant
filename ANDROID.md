# Polo Assistant на Android

Есть два способа установить приложение на телефон или планшет Android.

---

## Способ 1. PWA — без сборки, за минуту

Приложение уже является PWA (манифест + офлайн-кэш проверены).

1. Откройте сайт приложения в **Chrome** на Android (локальный адрес `http://<IP-компьютера>:7100` в одной Wi-Fi сети или опубликованный HTTPS-адрес).
2. Меню Chrome (⋮) → **«Установить приложение»** / **«Добавить на главный экран»**.
3. Готово: иконка на рабочем столе, полноэкранный запуск без адресной строки, работа офлайн.

Данные (журнал ТО, заправки, расходы) хранятся локально на устройстве. Резервная копия — «Настройки → Экспорт JSON».

> PWA не попадает в Google Play, но для личного использования ничего больше не нужно.

---

## Способ 2. Нативный APK через Capacitor

В проекте уже создана нативная обёртка: папка `android/` — готовый Gradle-проект (Capacitor 8, пакет `ru.poloassistant.app`). Весь код приложения — тот же веб-код из `dist/`, поэтому любые обновления веб-версии попадают в APK командой синхронизации.

### Что нужно установить (один раз)

1. **JDK 17+** — например, [Microsoft OpenJDK](https://learn.microsoft.com/java/openjdk/download) или Temurin.
2. **Android Studio** — при установке согласиться на Android SDK (Platform 35+, Build Tools).

### Сборка APK

```bash
# из папки app/
npm run build          # пересобрать веб-часть
npx cap sync android   # скопировать dist/ в android-проект

# дальше либо из командной строки:
cd android
gradlew.bat assembleDebug
# готовый файл: android/app/build/outputs/apk/debug/app-debug.apk
```

либо открыть папку `android/` в **Android Studio** → дождаться синхронизации Gradle → **Build → Build APK(s)**.

### Установка на устройство

- Скопируйте APK на телефон и откройте его (Android спросит разрешение на установку из неизвестных источников), или
- подключите телефон по USB с включённой отладкой и нажмите **Run** в Android Studio.

### Подпись релизной версии

Для обновлений поверх установленного приложения и публикации соберите подписанный APK/AAB: **Build → Generate Signed App Bundle / APK** в Android Studio (создаётся keystore — сохраните его, без него обновлять приложение нельзя).

### Особенности

- Данные хранятся в WebView localStorage — сохраняются между запусками, но **не** переживают удаление приложения. Используйте «Экспорт JSON».
- Офлайн-режим работает из коробки: весь интерфейс упакован в APK.
